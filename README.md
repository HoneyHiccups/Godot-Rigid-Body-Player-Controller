Rigid body player controller is a gdextension  that I made so that people using godot at some point will have a one stop shop for a rigid body controller without having to build one from scratch for every project.
The web build might have some shudders and hitching, the project was never really meant to be fully deployed on the web, in addition to that there seems to be differences with how input is passed from web and desktop so you mouse might feel a little off.

How to play
Press 'end' 'P' on you keyboard to focus on the screen escape will get you out of full screen 

Pressing '1' will lower your mouse sensitivity (you cant hold it it needs to be pressed and releases)

Pressing '2' will raise your mouse sensitivity (you cant hold it it needs to be pressed and releases)
Pressing 'control + r' will reset your the level

Pressing 'Page Down'  or 'T' till switch you to a debug third person view

Some of the key features are fully rigid body controller with all physical interaction that includes, dynamic gravity systems such as planets and rings, physics based puzzles, strafe jumping, and virtualized input.  

The web version dose not include multiplayer however there is a multiplayer build that you can sample, using the High Level multiplayer nodes. I have tested it up to 220 ping and it ran well (says way more about Godot multiplayer node then me) The hosting computer will have have a port forwarded.
